# 旧模型配置自动接管设计

## 目标

客户端遇到 `config.toml` 中与内部供应商模型完全相同的旧配置时，自动备份并将其迁入托管区块，不要求用户手工删除。真正不同的同名配置保持不变，并提供“使用客户端配置、保留手写配置、自动改名”三个处理方向。

## 等价规则

模型 ID、模型标识、API 地址、显示名称、接口协议、环境变量名及所有已设置的数值参数完全一致时才视为等价。字符串按 TOML 解码后的值比较，API 地址忽略末尾单个斜杠。缺失的可选数值和客户端中的 `null` 等价。

## 迁移

同步前解析非托管区块中的 `[model.*]`。等价区块先写入带时间戳的 `config.toml.desktop-backup-*` 备份，再从非托管内容移除，由客户端托管区块重新生成。一次同步只创建一个备份。

不同内容的同名区块不自动改动，错误携带模型 ID 和可选操作。冲突只阻止该模型被接管，不应让用户在不了解原因时丢失配置。

## 界面

完全相同的配置静默接管，并在模型弹窗中显示一次迁移结果。真实冲突显示明确的模型 ID 和处理选项。相同错误在消息区只保留一条，后续重复发生时更新原提示而不是继续追加。

## 测试

覆盖等价旧区块自动接管、备份内容、不同区块不被覆盖、可选参数比较、托管区块保留，以及重复错误提示去重。
